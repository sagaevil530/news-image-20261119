## The day in one picture

A newspaper front page for 19 November 2026:

- **Grand Theft Auto VI launches worldwide** — after 13 years, Rockstar's
  return to Vice City rolls out at midnight local time, from New Zealand to
  New York.
- **Severe Cyclone Akvan bears down on India** — red alerts and school
  closures along the east coast as landfall is forecast for noon on 20 November.
- **Voyager 1, a light-day from home** — NASA briefs the world on the first
  human-made object a full light-day from Earth.
- **Earth's missing billion years** — scientists say they may have solved the
  mystery of a billion years vanished from the rock record.

The photographic panels were generated for this entry; every word on the page
is typeset text, so nothing is garbled.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`). It needs no network and writes identical bytes on
every run.
